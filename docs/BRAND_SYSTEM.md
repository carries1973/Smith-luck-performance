# Smith Luck Performance — Brand System

## Brand promise

Smith Luck should feel disciplined, personal, capable and built for long-term performance. It must never look like a generic fitness template.

## Locked identity

- Primary name: **SMITH LUCK**
- Product name: **Smith Luck Performance**
- Supporting mark: Smith Luck shamrock/logo
- Heritage line: **EST 1971**, used subtly
- Tone: strong, athletic, direct and premium

Unrelated jersey, bird, typewriter or stock branding is prohibited.

## Established colour direction

The version 4 application uses these core tokens:

- Background: `#080b09`
- Primary surface: `#111713`
- Primary forest green: `#1e5a39`
- Brighter functional green: `#5fa979`
- Pale green text accent: `#b7d8c1`
- Primary text: `#f3f4ed`
- Border: `#29332c`
- Destructive state: `#df625f`

These values are the baseline. Changes require a deliberate brand decision, not routine UI cleanup.

## Interface rules

- Keep the dark background and forest-green hierarchy across every view.
- Use green for meaningful state, progress and primary actions—not decoration everywhere.
- Maintain readable type and touch targets during active workouts.
- Keep workout data dense but scannable on iPhone.
- Share headers, cards, set rows, timers, notes and completion controls.
- Preserve the current Smith Luck visual silhouette while improving function.

## Logo rule

Version 4 renders a CSS shamrock as a functional placeholder. The approved original Smith Luck logo should replace it when the permanent logo asset is added to the repository. Do not redraw or reinterpret the logo without approval.

## Change control

Any proposal that alters the logo, core palette, naming, typography character or overall visual identity must be identified separately from usability work and approved before implementation.
